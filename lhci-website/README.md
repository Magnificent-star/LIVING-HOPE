# LHCI Website — HTML/CSS/JavaScript

An original NGO website implementation inspired by the visual language of modern nonprofit landing pages.

## Files

- `index.html` — page structure and content
- `css/style.css` — responsive design system
- `js/script.js` — navigation, counters, scroll reveals, back-to-top and demo form behavior
- `assets/images/` — place your own images here

## Add your images

Replace the following files in `assets/images/`:

- `hero.jpg`
- `about.jpg`
- `program-1.jpg`
- `program-2.jpg`
- `program-3.jpg`
- `story-1.jpg`
- `story-2.jpg`

The current HTML uses gradient placeholders so the site still works before images are added.

## Customize before launch

1. Replace the placeholder contact details.
2. Replace sample impact numbers with verified LHCI figures.
3. Add real program and beneficiary stories.
4. Add official social media links.
5. Connect the contact form to your preferred email/backend service.
6. Add your official logo and favicon.
7. Review all text and accessibility labels.

## Run

Open `index.html` directly in a browser, or use VS Code Live Server for development.
