# Living Hope Community Initiative (LHCI) — Website

The official website for **Living Hope Community Initiative (LHCI)**, a nonprofit empowering children, youth, and vulnerable families through mentorship, education and skills support, and family/community empowerment programs.

🔗 **Live site:** [living-hope-community.vercel.app](https://living-hope-community.vercel.app)
🛠️ Built by [Azimu Digital](https://www.azimudigital.tech)

---

## About

Living Hope Community Initiative creates practical pathways for children, young people, and vulnerable families to live with hope, dignity, and purpose — working alongside communities, partners, volunteers, and local leaders to turn compassion into sustainable action.

This website serves as LHCI's digital presence: sharing its mission, programs, and impact, and giving visitors a way to volunteer, partner, or donate.

## Site sections

- **Home** — mission statement and hero call-to-action
- **About** — who LHCI is and its approach (Listen → Equip → Empower)
- **Programs** — Child Mentorship, Youth Empowerment, Family Support
- **Impact** — key numbers (lives reached, youth empowered, families supported, community programs)
- **Stories** — human stories behind the impact
- **Contact** — contact form, email, phone, and WhatsApp
- **Donate** (`donate.html`) — dedicated donation page

## Getting started

Clone the repository and open the site locally:

```bash
git clone https://github.com/Magnificent-star/LIVING-HOPE.git
cd LIVING-HOPE/lhci-website
```

If the site is static HTML/CSS/JS, you can open `index.html` directly in a browser, or serve it locally for a closer-to-production experience:

```bash
npx serve .
```

> If this project instead uses a framework/build tool (e.g. Vite, Next.js), replace this section with the actual install/run commands (`npm install`, `npm run dev`, etc.).

## Deployment

The site is deployed via **Vercel** at [living-hope-community.vercel.app](https://living-hope-community.vercel.app). Pushes to the `main` branch can be connected to Vercel for automatic redeployment.
